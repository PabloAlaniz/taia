<CardGrid>
  <Card title="Tablero para agentes" icon="list-format">
    Kanban con columnas por workspace, swimlanes, dependencias, subtareas, filtros guardados y
    actualizaciones en vivo por WebSocket.
  </Card>
  <Card title="Servidor MCP" icon="puzzle">
    36 herramientas para que los agentes lean, creen, muevan y comenten tareas desde Claude Code,
    Cursor o cualquier cliente MCP. Ver [Herramientas MCP](/taia/referencia/herramientas-mcp/).
  </Card>
  <Card title="Cualquier runtime" icon="random">
    OpenClaw, la API de Anthropic, Claude Code, Aider o Cursor, cada uno como adapter con sus
    capacidades declaradas. O ninguno: [modo standalone](/taia/inicio/elegir-setup/#sin-runtime-standalone).
  </Card>
  <Card title="Self-hosted" icon="seti:docker">
    Docker Compose con PostgreSQL. Para producción, Caddy con TLS. Todo el estado vive en la base.
  </Card>
</CardGrid>
